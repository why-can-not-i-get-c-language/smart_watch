# 功能要求

2026-10-31确认。STM32智能手表＋Android手机端，共14项功能。

| ID | 功能 | 完成行为 |
| --- | --- | --- |
| F01 | 时间与日期 | RTC计时、日历设置、手机校时和无效时间状态 |
| F02 | 定时振动提醒 | 提醒设置、到时触发、确认取消和参数保存 |
| F03 | 步数统计 | 运动采样、步数累计、清零与按日汇总 |
| F04 | 抬腕亮屏 | 看表姿态触发、按键唤醒和超时熄屏 |
| F05 | 持续低活动提醒 | 活动窗口累计、时长设置、振动提示与活动后复位 |
| F06 | 蓝牙同步与设置 | 手机连接、状态同步、校时、参数设置和重连 |
| F07 | 历史记录 | 带时间步数和事件记录，手机分页查询及CSV导出 |
| F08 | 电量估算与低电提醒 | 电池电压采样、估算电量、低电滞回与提示 |
| F09 | 低功耗管理 | 外设按需工作、主控STOP、唤醒及总线恢复 |
| F13 | 静止心率测量 | 红光/红外采样、接触质量判断和静止心率计算 |
| F14 | 血氧估算 | AC/DC比值计算、估算结果及无效状态 |
| F16 | 手动SOS | 长按发起与取消，手机确认打开短信或拨号页面 |
| F17 | 疑似跌倒与人工确认 | 冲击/姿态/静止窗口，振动倒计时与确认取消 |
| F19 | 无线固件升级 | BLE分包、长度和CRC校验、Boot/App及中断恢复 |

全部振动使用DRI0056（TM6605＋配套LRA）套装。电量与血氧以估算值标识。求助的BLE接收、手机操作和接收方送达分开记录。

各项功能的硬件、引脚、线路及实物验证信息见plan/design/functions/对应ID.md，共享供电与总线分配见plan/design/wiring.md。
