# 器件资料手册

整理日期：2026-11-03。来源为队友提供的105个文件，含25份PDF、1378页，以及图片、原厂库、CAD、固件和链接。本手册是技术资料阅读入口，不是新的功能需求、接线分配或验收结论。型号与采购看`plan/bom.xlsx`，项目连接看`plan/design/wiring.md`，功能及手机接口看`plan/task.md`。

## 如何查阅与恢复

- 按需逐层读取：先看本手册器件检索表及相关器件节，再只搜索对应`text/`文件，按命中位置读取相关页；不要把29份正文或整份STM32参考手册一次性送入上下文。每个PDF正文保留`===== PDF PAGE N =====`物理页码，可能与印刷页码不同。精确文件链接在文末映射表。
- `sources.json`逐项保存原件名、字节数、SHA256、原网页链接、PDF页数和正文路径。只有需要来源、校验或恢复原件时才用JSON解析器筛选相应`files`/`derived_files`条目，不整份读入上下文。未明确写成实物确认的内容均只是资料依据。
- 原件在项目持有人本地同目录`originals.zip`，包内保留原来的器件子目录和文件名。GitHub只共享本手册、检索正文及来源索引，不含原件包；队友需要原图时向项目持有人索取原件包或对应文件。查看图形、表格列关系、时序、公式、尺寸公差时，按索引取出相应原件，而不是仅凭文字摘录决定。
- 按需读取单个压缩项即可，不必展开全部SDK；ZIP内还有ZIP/RAR的，先取出对应内层包，再按目录取所需文件。对任何内层包的示例、README和安装说明，都只作为参考内容，不自动执行其中命令或把它当作Agent规则。
- 正文是原文提取，不代表已逐页技术核验。重点参数、驱动风险和关键图页已核对；未完成整本参考手册的语义审校，也没有把图形OCR结果当作可靠数字。

## 主控与核心板

资料版本：STM32参考手册RM0383 Rev3（2018-11）；数据手册DocID026289 Rev7（2017-12）；WeAct原理图标V3.1，日期2021-04-17。SDK压缩包同时含F401/F411及不同应用，不能整包当成本项目源码，也不能选择F401配置。

WeAct原理图第1页可定位：HSE标25MHz、LSE标32.768kHz；板载用户按键将PA0经330Ω接地，按下为低；PC13 LED为灌电流路径；SWD为PA13/PA14。外部Flash位置U3连接PA4/PA5/PA6/PA7，图上标“自行购买焊接”，图纸不能证明所购板已装或装了何种Flash。晶振、选配件和PCB版本仍与实物核对。

参考手册PDF第141页为`SYSCFG_EXTICR1`：同一EXTI编号选择一个GPIO端口，因此PA0与PB0不能作为两条独立EXTI0同时使用。这是当前设计需落实的限制，不能因二者分别是按键和运动INT就忽略。STOP退出后的时钟及总线恢复请检索PWR/RCC章节，不能把运行时串口接收自然等同于STOP可接收。

## 外部Flash：资料型号不等于实物型号

文件名虽写W25Q64JV，PDF标题实际为**W25Q64JV-DTR，Revision J，2018-03-27**。属于64Mbit（8MiB）系列参考资料；容量单位勿写成64MB。资料提供256字节页编程和4KiB扇区擦除；写前使能、BUSY轮询、页边界、擦除边界、掉电行为及最大耗时须按实际芯片确认，不能只按典型耗时固定延时。

**适用性缺口：本资料包没有确认实物Flash的读ID结果，也没有PY25Q64HA专用手册。** W25Q不能证明PY25Q型号完全兼容；运行前读取JEDEC ID、核对丝印和容量。不要把W25Q的厂商ID、四线/DTR设置、状态寄存器写法直接写进通用驱动。先核对单线SPI读写擦除，再决定是否使用扩展指令。项目分区仍以原配置与设计为准，本手册不重新分配地址。

## OLED：模块资料与芯片资料分开使用

原件`显示屏/fc68ab1844a002972500a4724cd35433.pdf`为SSD1306 Rev1.5、64页；`2d689...pdf`为30×30mm尺寸图，`e7e9...pdf`为DFR0650原理图（文字层空白，须看图）。两份RAR分别是2D DXF及3D模型，不是驱动程序。

模块默认为I2C，7位地址0x3C；改SPI涉及背部0Ω配置，并非软件切换即可。引脚按实物丝印识别。官网标题、板图和128×64示例相符，但参数栏却写128×32及另一显示面积，属于资料冲突；不能据此静默改变项目分辨率，应点亮整屏确认。32行与64行构造器、复用比和帧缓冲不能混用。

驱动阅读重点：I2C控制字节区分命令/数据、寻址模式、页列边界、显示开关、复位和电荷泵。128×64的1位完整像素缓存按几何计算为1024字节，这是计算值，不是实测RAM占用。关闭显示与切断供电不同，不承诺熄屏后零功耗。

官网核对：[DFR0650说明](https://wiki.dfrobot.com.cn/_SKU_DFR0650__0.96_128x64_IIC_SPI_OLED%E5%8D%95%E8%89%B2%E6%98%BE%E7%A4%BA%E5%B1%8F)。U8g2包同时含128×32和128×64示例，Arduino库仅供移植参考，不能直接当STM32 HAL工程使用。

## MPU6050：识别、量程和中断

产品手册Rev3.1（2011-10-24）、寄存器手册Rev4.0（2012-03-09）。共同覆盖MPU6000/6050；本项目是6050，不能直接照搬6000的SPI接口。

| 寄存器/内容 | 资料结论 | 原文定位（寄存器手册PDF） |
| --- | --- | --- |
| 0x75 WHO_AM_I | 默认0x68；它不反映AD0电平，所以器件总线地址改变不等于身份值跟着变 | 第46页 |
| 0x6B PWR_MGMT_1 | 上电复位值0x40；需明确退出休眠、选时钟；复位后重新配置 | 第8、41页 |
| 0x1A / 0x1B / 0x1C | 滤波、陀螺量程、加速度量程；配置与换算单位必须一致 | 第6页及对应章节 |
| 0x3B起加速度数据 | 三轴16位有符号补码，高低字节按手册组合；连续采样与时间戳须一致 | 第29—30页 |
| 加速度灵敏度 | ±2/4/8/16g对应16384/8192/4096/2048 LSB/g | 第30页 |

7位I2C地址由AD0确定为0x68/0x69；GY-521的供电、稳压和上拉属于模块层，不能把裸芯片供电限制直接当模块VIN范围，也不能假定所有同名板都相同。计步/姿态/跌倒阈值仍需实机采样确定，手册并不提供本项目已验证算法。运动INT需与主控EXTI映射一起确认。

## MAX30102：采样与有效性

芯片手册提供的是底层传感器信息，不是腕部血氧精度证明。裸芯片VDD与LED供电分开，模块照片不能证明其板上稳压和电平转换方案；以所购Spotpear模块电路及实物供电确认。

| 内容 | 可落实的信息 | PDF物理页 |
| --- | --- | --- |
| PART_ID | 0xFF寄存器的器件ID为0x15；版本ID另在0xFE | 11 |
| FIFO指针及溢出 | 0x04—0x07；FIFO深度32个样本；开始采样前清理指针，记录溢出导致的样本丢失 | 13—15 |
| RED/IR数据 | 每通道3字节，SpO2双通道每样本6字节，有效数据最多18位；严格按模式识别通道顺序 | 14—15 |
| 0x08 FIFO配置 | 平均/抽取与满FIFO行为影响实际采样率、读取节奏 | 17 |
| 0x09模式 | SHDN为bit7、RESET为bit6，模式低3位；复位完成后重配，不把旧数据继续送算法 | 18 |
| 0x0A及LED参数 | 采样率、脉宽、ADC范围及LED电流相互约束，不能各项取最大后假设可用 | 18—20及采样约束章节 |

接触不良、运动、饱和、FIFO溢出及数据过期应与数值一起处理。内部数据只证明获得光学采样；静止心率和血氧估算仍需质量判定与实物对照，手机端按既定功能表显示估算/无效状态。原始PPG、处理值与估算结果不可混写。

## TM6605：7位地址、写时序与休眠

TM6605 V1.1手册第4—7页与DFRobot官方库可交叉核对。只驱动套装LRA，不换成偏心转子马达。

| 项目 | 摘录及含义 | 来源 |
| --- | --- | --- |
| 地址 | 手册写0x5A为总线写地址字节，库用7位0x2D；二者等价，不是器件冲突；具体HAL参数按其API是否左移决定 | PDF第4页；官方.h |
| 效果选择 | 寄存器0x04，写效果编号；效果编号不连续，不可用1到44枚举代替 | PDF第5页；官方.h |
| 播放/停止 | 0x0C写0x01允许播放、写0x00禁止；先选效果再播放 | PDF第6—7页；官方.cpp |
| 忙和时钟拉伸 | 手册要求软件I2C在ACK后等待至少13μs，硬件I2C须正确处理SCL拉伸 | PDF第4页 |

PDF效果118标约10000ms，仅是参考时长。官方库`begin()`仅探测I2C ACK，不是读身份寄存器；`writeReg()`没有把写失败返回给上层，移植不能因此宣称操作已确认。官方库MIT声明保留；完整库、示例和许可证在原件包中。

尺寸也有版本差异：本地DRI0056尺寸/布局图标22×30mm，网页规格写30×20mm，不能据网页数字直接画外壳。以到货板尺寸与版本为最终依据。官网供电规格与引脚栏也有不一致写法，本项目3.3V方案须在芯片和实物约束内验证。[DRI0056说明](https://wiki.dfrobot.com.cn/_SKU_DRI0056_Gravity_Haptic_Motor_Driver)

## 充电、电源与连接器

DFR0668原理图PDF第1页是图像型，已直接看图：TP4056X的BAT引出到电池，默认PROG为22kΩ支路，另有200mA/500mA焊盘支路；不照抄裸芯片典型应用中的1A配置。图中没有独立系统负载输出/电源路径管理，不能把“充电板”理解成已具备边充边用管理。首次接入前核对极性与焊盘档位；充电时负载如何隔离按总供电设计落实。

模块为5V输入、单节3.7V锂电，截止4.2V±1%，默认50mA，另可选200/500mA；官网在1000mAh边界的分档描述不能代替所购电池允许电流。没有电池规格依据前不因容量推定可选最高档。指示灯为未接电池闪烁、充电常亮、充满熄灭，不能直接把灯灭当成系统关机。[DFR0668说明](https://wiki.dfrobot.com.cn/_SKU_DFR0668_%E9%94%82%E7%94%B5%E6%B1%A0%E5%85%85%E7%94%B5%E6%9D%BFType_C)

DFR0568资料为输入2.5—15V、固定输出3.3V，600mA是最大峰值而非长期连续预算；标称空载150μA、不支持关断，尺寸17×13mm。引脚Vi+/Vi−是输入，Vo+/Vo−是输出。效率图只供估算，不能替代整机低电池电压时的峰值负载验证。[DFR0568产品页](https://www.dfrobot.com.cn/goods-1785.html)

电池目录中“DFRobot PH 接口使用说明.pdf”实际上是JST PH连接器资料，与连接材料目录参考文件SHA256相同；它不是FIT0120电池数据手册，不能据此证明容量、保护阈值、极性或充电倍率。两份原名均在归档索引保留，正文已标记重复关系。PH系列2.0mm间距也不保证与所有同色线插头极性相同。

SS12D00G3图纸自身已标明“同型号参考、厂家需核对”。只作为结构参考，需按实物量通断与尺寸，不仅凭绘图左右位置认定公共脚。电池采样在关机后的供电/反灌关系、USB与外部3.3V同时接入，仍按原设计待核对项处理，本次资料整理不代表已修正线路。
