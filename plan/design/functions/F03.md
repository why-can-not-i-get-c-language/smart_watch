# F03 步数统计

## 功能与代码

运动采样、步数累计、清零与按日汇总。

## 器件、引脚与线路

GY-521线路已于2026-11-08按下表完成本步用户验证；未接的中断及其他后续用途仍属设计分配。按模块丝印接线，禁止仅凭排针位置推断。

## 公共电气约束

3.3V逻辑并共地；共用I2C时核对并联上拉，先以100kHz扫描；I2C地址按7位保存，由端口适配HAL寻址。上电前测电源短路、极性及电压。USB台架供电和外部稳压输出相互隔离。相关外设掉线必须返回错误，不阻塞主循环。

### F03-P01 本次实现与验收

2026-11-08完成驱动及页面集成。身份必须读到0x68，初始化异步推进并回读配置：50Hz、加速度±8g（4096LSB/g）、陀螺±250度/秒（131LSB/(度/秒)）、DLPF=4。按DATA_RDY连续突发读取六轴数据；接口及Keil诊断保存g、度/秒和主控读取开始时刻的毫秒时间戳，OLED加速度按mg换算显示。`CFG 50HZ`是配置值，`ACT HZ`是实际收到新样本的窗口计数除以经过时间，不代表外部仪器测得的传感器精度。调度延误可能漏样，诊断保留实际间隔及大于40ms的间隔次数，不将其当作精确丢样数。

身份/配置不符及总线失败时清空有效样本；离线每秒节流重新初始化，不要求主控复位。100ms未有新数据则样本无效；连续1秒无新数据会超时并重新配置。初始化等待不忙等，单次推进最多一个有超时的I2C事务。软件mock覆盖身份错误、配置读回、量纲/符号、无新数据、掉线与重配恢复、超时及毫秒回绕，另检查页面循环、编辑保存/取消和掉屏草稿保留，共643项断言通过。全部主机检查不能代替实物结果。

Keil原`smart_watch`目标使用Arm Compiler 6.24，启用`-Oz`体积优化以适应当前链接器32KB限制；本次目标构建0错误0警告，BIN为19760字节，已核对版本与首启向量。未变更工程层级、源码集合或用户IDE配置。计步、抬腕、跌倒及低功耗均未在本任务实现。

复刻与验收操作：

1. 断电接线VCC→3V3、GND→GND、SCL→PB6、SDA→PB7、AD0→GND；INT/XDA/XCL留空，按模块丝印接线。
2. 烧录本次版本，自检后默认MPU页显示`ID 68 ONLINE`、更新的主控时间戳与计数。静止任意倾角看三轴合成值接近1g，不要求X、Y单独为0；ACT HZ应反映实际收到的样本。
3. 仅断开MPU的SDA支线，样本应无效且LED/OLED继续；接回后无需复位恢复。不将公共SDA整线断开误当成只断MPU。
4. 板载KEY长按循环MPU→振动→时间→MPU；回归振动短段取消、切页取消及时间编辑保存/取消。OLED断线接回应恢复当前页，运动采样在其他页继续。

本次实物验证未覆盖：陀螺各轴独立对照、全量程/六面标定、长期频率精度、供电电压及电流。用户反馈本版时间未设置，不能将切页时状态正常记为日期设置保存/取消通过；本版切出振动页取消也未单独确认。以上保留为限制，不扩写成已实测功能。计步与清零留F03-P02。


### F03-P02 计步与清零（待用户验收）

待补验固件`F03-P02-20261108-02`已另存为`code/Build/Objects/smart_watch_F03-P02-20261108-02.hex`，同名AXF/BIN一并保留，避免后续任务构建覆盖。01版于2026-11-08获用户确认静止30秒不增加，但小幅用力晃动会计数；用户要求降低灵敏度并增加行为判定。本任务尚未通过实物验收，01版静止结果不能自动替代02版结果。本步只在RAM累计本次开机步数，界面明确标为`SESSION RAM`；重启归零，不是按日累计。默认进入计步页，MENU长按清零；KEY长按循环计步、MPU、振动、时间页，编辑中不切换。所有页面共用同一份采样和计步状态，掉屏不主动清零。

02版在三轴模长平滑及自适应基线之上，改为等完整谷—峰波形结束后再判定：峰阈值0.14g、谷阈值-0.10g、峰谷幅差至少0.32g；谷持续40～900ms，峰持续60～700ms，完整波形不超过1800ms。候选峰间隔300～1800ms，且与近期平均间隔的差值不超过25%或80ms中的较大值。连续8个合格候选才一次补记，之后逐个累计；界面以`CHECK WALK n OF 8`显示未确认进度，候选不混入已确认步数。异常波形、节律中断和离线丢弃未确认候选，保留已确认累计。

连续8候选确认思路参考[ADI AN-2554](https://www.analog.com/en/resources/app-notes/an-2554.html)，本项目自行实现峰谷/时间规则，未移植其器件驱动或引用其精度为本项目结果。当前是规则筛选，不是经过数据集训练的活动分类器；短程少于8个候选可能不计，持续模仿步态波形和节律的挥手仍可能误计。提高阈值也可能漏掉幅度较小的实际脚步，必须用用户的晃动动作和真实步行分别验证。原始读数、处理信号和算法步数分开保存。

每个新样本只消费一次。无效/非有限/超范围/过期样本、重复或倒序时间不增加计数；大于100ms的样本间隙和离线保留累计并重新预热，不补造步数。支持毫秒回绕，累计到UINT32_MAX后饱和；不实现按日汇总、历史保存或手机同步。

02版软件检查覆盖静止/缓慢转动、小幅周期运动、短阵晃动、非规律周期、窄脉冲、连续确认/超时丢弃、合理步频、掉线保数与恢复、重复/倒序/过期时间、回绕、非有限值、清零及饱和。32项行为断言及逐样本累计一致性检查通过，另通过候选进度/清零显示、四页循环、掉屏保留和时间编辑回归。三组相同模拟输入（低幅周期、短阵、非规律周期）在01版均输出39，在02版均输出0；6组20周期持续波形仍各输出19。这是合成数据对照，不是用户晃动或真实步行结果。已显式检查并保留“长时间同形同节律晃动仍可能计数”的限制。Keil原目标0错误0警告。

2026-11-08用户确认02版“单纯的晃动没法持续触发步数”，该负例复测符合当前预期，但未提供实际步行计数。用户明确要求真实步行对照先跳过，待焊装完成后再做；F03-P02继续保持等待硬件验证，不标完成、不据此放行依赖任务，02版固件保留。

焊装后待验：人工数步的真实步行对照并报告误计/漏计，再补齐清零、掉线及页面等未确认项。02版静止结果尚未单独反馈，不能沿用01版结果当作02版通过。每次只给用户一个实际场景。面包板上的节律摆动不能代替真实步行误差对照，也不能仅凭负例不计就宣布算法准确。
