# F02 定时振动提醒

## 功能与代码

提醒设置、到时触发、确认取消和参数保存。

## 公共电气约束

3.3V逻辑并共地；共用I2C时核对并联上拉，先以100kHz扫描；I2C地址按7位保存，由端口适配HAL寻址。上电前测电源短路、极性及电压。USB台架供电和外部稳压输出相互隔离。相关外设掉线必须返回错误，不阻塞主循环。

## 验证与留档

### F02-P01 TM6605套装驱动

2026-11-07用户确认DRI0056驱动板及配套LRA均已到手，本版尚未接线和实物验收。固件`F02-P01-20261107-01`，原工程/目标`smart_watch`保持不变；下载`code/Build/Objects/smart_watch.hex`，调试文件为同目录`smart_watch.axf`。BIN为26792字节，SHA256为`41c93a8d8ac18a172a57d5ee378224d0700a811b924f3fd065befc495def7576`。

软件结果：Keil 0错误0警告，目标/非目标语法检查通过；56项输入、15个F组及158项条目、ELF/版本/向量已核对。模拟I2C验证44个合法效果及212个非法值、7位寻址、单步最多一次传输、帧顺序及5ms间隔、停止/休眠抢占、唤醒首命令丢弃、12000ms保护停止、毫秒回绕、各阶段超时/NACK终止与恢复。非目标API不伪报硬件成功。UI检查振动/时间页切换、页面重连、无重复命令下发、原编辑草稿/取消/UTC+8保存回归及ACK/错误帧。RTC、按键及I2C总线实现与验收版一致（换行规范化后比较）；上述软件结果不代表马达实测通过。

先断电，按丝印连接驱动板VCC→核心板3V3、GND→GND、SCL→PB6、SDA→PB7；与OLED并联共享总线。配套LRA只接驱动板的马达插座或OUTP/OUTN，不把输出一端接地，不直接接GPIO，不换成ERM偏心马达。端子位置以实物丝印为准，不按线色猜测；保留原OLED、三键、ST-LINK及PA9↔PA10回环。

控制与反馈口径：

| 振动验收页操作 | 动作和判断 |
| --- | --- |
| 菜单PB12短按 | 请求效果14短振动；按手册约190ms仅为参考，实际感觉由用户确认 |
| 菜单PB12长按约2秒 | 请求效果118长振动，参考约10秒；不是定时提醒或闹钟触发 |
| 板载用户KEY短按 | 请求停止，可抢占尚未完成的播放命令；不是NRST |
| SOS PB13短按 | 停止后发送休眠命令123，只表示命令发送，不证明持续低功耗 |
| SOS PB13长按约2秒 | 显式唤醒并确认停止，不自动播放；随后可再按菜单播放 |
| 板载用户KEY长按约2秒 | 切换振动验收页/北京时间首页；切出振动页会请求停止，时间页继续保留原菜单编辑功能，编辑中KEY长按不切页 |

本版上电完成原显示自检后默认HAPTIC CHECK，不自动播放；初始化会探测0x2D并两次确认停止。PENDING是本地命令尚未完成，LAST ACK OK仅表示整个命令序列传输ACK，不是身份识别、实测马达忙位或已确认运动。错误会显示IO ERROR/TIMEOUT/NOT READY等，不能沿用旧成功；离线最多每秒重试初始化，接回只停止，不重播旧效果。

播放前先发送停止作为唤醒，间隔至少5ms再确认停止，然后选择效果并启动；每次推进最多一次I2C调用，无长延时。重播保护间隔采用手册参考时长加200ms，是软件估计；保护期间可按KEY停止。若请求后仍未停止，最长12000ms会再排队保护性停止，该时间不是实测效果长度。

休眠限制：手册明确SCL下降沿可唤醒TM6605且首条命令可能丢弃。OLED和台架诊断仍访问共享总线，因此CMD SLEEP与LAST ACK OK只证明休眠指令已发送；本项不把“马达不振”当作持续保睡/功耗证明。持续保睡、电流及共享总线静默策略留F09。设备只支持写入，不读取或编造身份/真实忙寄存器。

由用户逐项验证：

1. 接线确认后下载本版并复位；LED及显示自检正常，进入HAPTIC CHECK，初始化最终LAST ACK OK，马达不应自行振动，UPTIME增加。NACK时记录错误行，不按在线通过。
2. 菜单短按有清晰短振动；长按有较长振动。长振动过程中短按板载KEY，应及时停止，LED和显示继续，无卡死；停止后再试短振动，实际重新触发要确认，不能仅凭ACK判通过。
3. SOS短按后页面CMD SLEEP/LAST ACK OK且马达不继续振动；SOS长按后CMD WAKE/LAST ACK OK，随后菜单短按可再次振动。这里只验收休眠命令及唤醒重播，不确认静态功耗。
4. 保持电源与公共地，仅拔开驱动板支路的SDA（不拔OLED支路），请求播放应报错、不能显示成功，LED和OLED继续；接回后无需复位恢复初始化，不能自动重播，用户再次请求才播放。
5. 板载KEY长按切到北京时间页，时钟继续，菜单进入编辑、取消/保存仍正常；切回振动页可继续测试。OLED支路SDA断开接回后恢复当前模式，LED继续。

必要时观察`diag.haptic_request_status`（请求是否接受）、`haptic_process_status`（本次推进结果）及`diag.haptic`快照（ready/busy/command/effect/status/completed_count）；get_state返回OK只说明元数据复制成功。用户实物结果：待反馈；F02-P01尚未硬件验收或推送。提醒设置、到时逻辑和参数持久化仍未实现，不据本项认为整个F02完成。
