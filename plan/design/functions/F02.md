# F02 定时振动提醒

## 功能与代码

提醒设置、到时触发、确认取消和参数保存。

## 公共电气约束

3.3V逻辑并共地；共用I2C时核对并联上拉，先以100kHz扫描；I2C地址按7位保存，由端口适配HAL寻址。上电前测电源短路、极性及电压。USB台架供电和外部稳压输出相互隔离。相关外设掉线必须返回错误，不阻塞主循环。

## 验证与留档

### F02-P01 TM6605套装驱动

当前固件`F02-P01-20261107-04`，使用固定工程/目标`smart_watch`。烧录`code/Build/Objects/smart_watch.hex`，调试文件同目录`smart_watch.axf`；BIN为27064字节，SHA256为`0a345fa476bce6826cbe94769f39650b52f73b25a9ffe5a0577f0db157348ef4`。04版撤回03版未奏效的连续两字节发送对比，恢复02版的可取消短振动序列；软件实现逐文件核对一致，仅版本标识与实测限制注释更新。本次Keil构建0错误0警告，版本与向量核对通过；复用02版软件检查，04版仍待用户烧录。

实物事实（2026-11-07）：DRI0056与配套LRA已连接，初始化、短效果14和长效果118曾确认正常。01版通过Mem_Write、03版通过Master_Transmit连续发送寄存器/数据，两者STOP和SLEEP均得到ACK却未中断118；用户进一步确认118约10秒自行结束。未发现写入地址/命令字节错误，更换发送接口未解决问题；现有证据不证明所有控制方式都无法中断，也不证明手册不适用于本套装。官方示例等待长效果结束后才停止，未覆盖中途停止。02版短段序列的KEY停止和SOS取消均由用户确认符合标准；其他驱动验收项尚未完成，不将整个F02或F02-P01标为通过。

接线保持不变：驱动板+→3V3、−→GND、C→PB6（SCL）、D→PB7（SDA），与OLED共享100kHz I2C1。配套LRA只接马达插座或OUTP/OUTN，不把任何差分输出接地或主控GPIO，不换成ERM。保留OLED、三键、ST-LINK及PA9↔PA10回环。

| 振动验收页操作 | 动作和判断 |
| --- | --- |
| 菜单PB12短按 | 请求效果14短振动；约190ms仅为手册参考值，以实物为准 |
| 菜单PB12长按约2秒 | 请求约10秒效果14间歇短振动序列，不是定时提醒或闹钟触发 |
| 板载用户KEY短按 | 取消后续段并发送停止；当前短段自然结束，不是暂停后续播或NRST |
| SOS PB13短按 | 取消后续段并发送休眠命令123；当前段自然结束，不证明持续保睡 |
| SOS PB13长按约2秒 | 显式唤醒并发送停止，不自动播放；随后菜单可重新播放 |
| 板载用户KEY长按约2秒 | 切换振动页/北京时间页；切出请求取消，编辑中不切页 |

上电显示自检后默认HAPTIC CHECK，不自动振动；初始化探测7位地址0x2D并两次发送停止。PENDING及busy只表示本地命令待发；LAST ACK OK及completed_count只表示整条命令传输成功，不是芯片身份、真实忙位、运动或停止的测量。错误显示IO ERROR/TIMEOUT/NOT READY等；离线最多每秒重试初始化，接回不重播旧效果。

可取消提醒使用tm6605_alert(duration_ms)，按手册短效果时长加200ms间隔重复效果14，单次推进最多一个传输且间隔至少5ms。停止、休眠、切页、到期或错误均取消后续段；保留当前段的重播保护间隔。raw play接口仍支持原有44个效果，但不可依赖STOP中断内部长效果；12秒保护写入同样不是物理中断保证。短段约190ms为参考值，不是实际停止延迟保证。

休眠限制：SCL下降沿可唤醒TM6605，首条命令可能丢弃。OLED和台架诊断继续访问共享总线，CMD SLEEP/LAST ACK OK仅表示命令发送，不代表持续睡眠或低电流；持续保睡、电流及总线静默策略留F09。器件只支持写入，不编造身份或真实忙寄存器。

用户验收项目：

1. 本版烧录后上电显示自检、LED及UPTIME正常，HAPTIC CHECK初始化最终LAST ACK OK，马达不应自行振动。
2. 菜单短按有短振动，长按出现约10秒间歇序列；中途KEY短按后松手0.5秒内停止且不再触发，显示CMD STOP，LED和显示继续；随后可再次播放。02版KEY取消已通过，04版待复核。
3. 序列中SOS短按同样取消，显示CMD SLEEP/LAST ACK OK；SOS长按显示CMD WAKE/LAST ACK OK且不自动播放，再短按菜单有新振动。02版SOS取消已通过，04版唤醒重播仍待实测。
4. 保持电源和公共地，仅拔驱动支路SDA，播放请求应报错而LED/OLED继续；接回无需复位恢复初始化、不自动重播，再次请求才播放。该项待实测。
5. KEY长按切到北京时间页，时钟继续、原时间编辑/取消/保存正常；切回可继续振动，OLED支路SDA断开接回恢复当前模式。该项待实测。

软件基线：02版已检查44合法/212非法效果、7位寻址、帧序/5ms间隔/单步一次发送、各阶段取消、到期、唤醒首命令丢弃、超时/NACK终止、恢复不重播和计时回绕；UI页切换、草稿/取消/UTC+8保存及掉屏恢复通过模拟检查。上述软件检查不代替实物。必要时观察diag.haptic_request_status、haptic_process_status及diag.haptic（含本地alert_active），get_state返回OK仅表示元数据复制成功。提醒设置、到时逻辑和参数持久化未实现。
