# F05 持续低活动提醒

## 功能与代码

活动窗口累计、时长设置、振动提示与活动后复位。

## 器件、引脚与线路

复用F03已验证的GY-521采样线路和F02的DRI0056套装驱动线路。本功能的低活动场景尚未实物验证，不新增接线。

| 硬件信号 | 主控或电源端 | 连接信息 | 限制与核对项 |
| --- | --- | --- | --- |
| GY-521 VCC / GND | 3V3 / GND | 模块电源及公共地 | 核对模块稳压、电平及实际供电要求 |
| GY-521 SCL / SDA / INT | PB6 / PB7 / PB0 | I2C1与运行时DATA_RDY中断 | AD0接地、原始ID0x68及采样已验证；XDA/XCL不用 |
| DRI0056 电源 / 地 | 3V3 / GND | 套装驱动板电源及公共地 | TM6605驱动配套LRA，马达只接驱动输出端 |
| DRI0056 SCL / SDA | PB6 / PB7 | 共享I2C1 | 7位0x2D；沿用已验收的效果14可取消短段序列 |
| F411板载RTC/LSE | 板内连接 | 板内连接 | 核对32.768kHz晶振实物；不外接GPIO |
| ST-LINK SWDIO / SWCLK / GND | PA13 / PA14 / GND | 调试器信号与公共地 | 参考电压和供电引脚依具体下载器说明；避免多路电源并联 |

## 公共电气约束

3.3V逻辑并共地；共用I2C时核对并联上拉，先以100kHz扫描；I2C地址按7位保存，由端口适配HAL寻址。上电前测电源短路、极性及电压。USB台架供电和外部稳压输出相互隔离。相关外设掉线必须返回错误，不阻塞主循环。

### 行为与页面

只按传感器连续有效时的算法确认步数判定低活动，不是坐姿或佩戴识别。使用单调毫秒时钟，不依赖RTC。观察中无新增确认步数达到设置时长时仅通知一次；确认、取消或5秒自动结束后保持NOTIFIED，出现新增步数后才重建下一窗口。会话计数清零、传感器失效、预热或大于1秒的调度间隙重建观察连续性，不把离线时间算为低活动。确认候选所需的算法延迟仍存在，真实动作效果待焊装后验证。

功能菜单新增ACTIVITY，5项滚动显示。KEY短按将时长草稿增加5分钟（5～120循环），MENU短按切换使能草稿，MENU长按保存并应用；SOS短按确认，SOS长按重读并丢弃草稿，KEY长按返回。SET与SAVED分开，保存中不提前更新SAVED。旧配置默认30分钟/关闭，仅显式保存才升级；保存分钟或使能变化后重新计时，重启不恢复旧窗口或旧振动。

在ACTIVITY详情页同时短按MENU和SOS可启动一次15秒快速测试窗口。该窗口只在RAM中生效，不修改已保存的分钟配置；测试结束或确认后恢复已保存配置。

快速测试版 `F05-P02-20261128-02` 在上述入口基础上只增加15秒测试窗口，正式分钟配置、共享参数载荷和普通按键行为不变。目标构建0错误0警告，Code=47680、RO-data=3880、RW-data=128、ZI-data=65528；新BIN为51688字节，SHA256 `0705bbe565953b3ef6c0e26a8b11e421dfd891fc87db023abd1b69106e5776b0`。该版本15秒快捷测试已实测通过，范围见下段。

快速测试验收（2026-11-28）：用户确认已烧录 `F05-P02-20261128-02`，进入ACTIVITY后执行MENU+SOS快速测试，15秒窗口、测试提示、低活动提醒及KEY/SOS停止路径符合预期。该结果只覆盖快速测试入口和对应触发/停止路径，正式5分钟以上低活动观察、保存配置、活动后复位及并发提醒仍未验收，F05不因此整体完成。

到时唤醒并请求一次5秒短段序列，显示MOVE KEY ACK；KEY/SOS在任意页面停止并消费整个手势。马达忙时最多等待30秒，超过则报错并消耗本窗口通知，不无限重试。驱动传输/启动超时错误保留，不把ACK当物理振幅。定时提醒优先：先确认低活动序列停止，再执行一次性提醒；驱动短段保护间隔的未受理请求可在一次性提醒原有5秒宽限内等待，不重播已受理命令。待发送的低活动通知可随KEY/SOS取消，但不吞掉手动振动页的停止操作。确认低活动通知不会取消未来的ARMED定时提醒；确认当前定时提醒会同时清除待发送的低活动通知，避免紧接着补振。

共享载荷v3及兼容规则见F07.md。计数、一次性提醒延时和低活动配置分别合并其他属性的最新已提交值，未知载荷保留。手机端设置能力缺口统一记入task.md的APP-04，当前D3命令和GetStatus语义不变，不代写手机端。
